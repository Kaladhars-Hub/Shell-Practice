# Shell-Practice 🐚

A hands-on collection of Shell scripting exercises built while learning Linux automation and Bash programming from scratch.

## 📌 What This Covers

- Variables, data types, and user input
- Conditional statements (`if`, `case`)
- Loops (`for`, `while`, `until`)
- Functions and reusable script blocks
- File and directory operations
- Process management basics
- Real-world automation mini-tasks

## 🎯 Purpose

This repo documents my learning journey into Shell scripting — a foundational skill for any Cloud/DevOps engineer working with Linux servers, automation, and infrastructure management.

## 🛠️ Tech Used

- **Language:** Bash / Shell
- **OS:** Linux (Ubuntu)

## 🚀 How to Run Any Script

```bash
git clone https://github.com/Kaladhars-Hub/Shell-Practice.git
cd Shell-Practice
chmod +x script-name.sh
./script-name.sh
```

## 📚 What I Learned

Working through these exercises helped me get comfortable with Linux command-line operations, writing reusable scripts, and understanding how automation reduces manual effort — directly applicable to cloud operations and DevOps workflows.
